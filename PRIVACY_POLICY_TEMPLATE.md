# NuScan privacy policy draft

NuScan is a free, offline-first document utility developed by NudroidLabs. Core document operations such as PDF conversion, compression, OCR, signing, QR generation and password protection are designed to run on the user's device. NuScan app code does not intentionally upload document contents to a NudroidLabs server.

NuScan does not contain advertising or a paid subscription system.

NuScan uses Google Play services for the document-scanner interface and QR-code scanner interface. Those Google components may process information according to Google's applicable terms and privacy documentation.

When automatic update checks are enabled, NuScan makes a network request to the official NuScan GitHub repository to read update metadata. If the user chooses to download an update, the APK is downloaded from GitHub Releases. NuScan verifies the package and update file before opening Android's installer.

Before publishing this policy, replace this draft with verified production details, a contact method, applicable retention information and any legally required regional disclosures.
